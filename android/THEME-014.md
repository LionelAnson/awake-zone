# 0.1.4：应用内主题设置与华文中宋

日期：2026-10-01。最终构建：`20261001-103300-023`。

## 交付行为

- 外观设置只在应用内。桌面保留 4×2、2×1 原布局，两种时间及标签、百分比、刻度；休息或刷新暂停时沿用原提示。没有加入桌面设置按钮、调色控件或额外常驻说明。
- 提供通透浅灰、米白、深灰、雾蓝、浅绿预设；背景支持自定义六位 RGB 色值与 0—100% 不透明度。
- 字色可选自动、黑色、白色、自定义；自定义字色同时用于刻度。背景透明度不改变文字透明度。
- 应用内即时预览，点击“保存并应用”后才更新所有组件。旧设置保留作息、刷新开关、透明度与字色；新增色值使用默认值。
- 设置、时钟数字、中文标签与刻度统一使用华文中宋。仍是半透明底色，没有新增实时背景磨砂。

## 字体的实际兼容处理

首次构建使用 XML `fontFamily`。应用内预览正确，但 Android 16 Launcher3 的实际桌面仍使用系统字体，刻度的 Canvas 字体则正常。现场保留在 `03-home-font.png` 和 `01-settings.png`。

最终方案在应用进程加载原组件布局并用华文中宋绘制，再以一张透明图片通过 RemoteViews 提交给桌面。根据组件尺寸选用布局，单张图片上限 480,000 像素（约 1.9 MB）；没有采集屏幕或壁纸。只在显示内容、外观或尺寸变化时提交更新。整张组件保留时间、百分比和状态的无障碍描述，以及点击打开设置的行为。

字体来自本机 STZHONGS.TTF，完整复制、未裁剪；APK 中的字体 SHA-256 与原文件一致。版本和版权记录见 [FONT-NOTICE.md](FONT-NOTICE.md)。
