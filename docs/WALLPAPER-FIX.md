# 0.3.1 壁纸修复、百分比与快捷键

日期：2026-09-30。当前测试平台为 Windows 11 x64；保留 macOS 工程，未在 macOS 运行。

## 壁纸错误原因与修复

本机只读诊断中，Windows 壁纸接口返回 2 条显示器记录：第 0 条的矩形为 `(0, 0, 1920, 1080)`，壁纸文件存在；第 1 条读取矩形返回 `0x80004005`，矩形为空。原实现遇到第二条无效记录后直接终止，所以当前有效屏幕的壁纸也无法显示。

新版跳过无法读取或空矩形的记录，再匹配组件所在屏幕。微软的 [GetMonitorRECT 文档](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nf-shobjidl_core-idesktopwallpaper-getmonitorrect)也说明接口可包含已断开屏幕；本机实际返回的失败码如上，不假设所有机器都返回相同错误码。

- 主接口失败时，单屏环境尝试系统壁纸备用接口；多屏时不把主屏壁纸错误地用到其他屏幕。
- 暂时失败时保留上次成功的图片，按 5 秒轮询并带退避重试；连续 3 次失败才显示提示。
- 恢复后清除壁纸错误提示，其他功能的错误仍保留。
- 图片成功解码后才更新缓存标记。壁纸加载不阻塞时钟更新。

## 显示与操作

- 百分比固定两位小数，例如 `0.00%`、`37.50%`、`87.50%`。
- 清醒期向下截断，最多 `99.99%`；到入睡边界才显示 `100.00%` 与个人 `24:00`。
- 按最新要求取消日间／夜间模式和明暗底色覆盖，只对原色壁纸做模糊。以 32×20 取样检测组件下方区域的平均线性亮度，低于 0.18 用白字，灰色／亮背景用黑字。移动、调整尺寸或更换壁纸时重新判断，系统颜色模式不影响组件。
- Windows 全局快捷键为 **Ctrl + Shift + Win + Z**：第一次切到置顶浮窗，第二次回到桌面层，保持位置；按住不连续触发。
- 返回桌面时先清除顶层窗口的置顶状态，再改为桌面子窗口，避免 Windows 保留置顶标记。
- Windows [RegisterHotKey](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-registerhotkey) 没有 Fn 修饰键，所以无法强制同时按 Fn。额外按 Fn 是否影响输出取决于键盘固件，未验证用户键盘的 Fn 组合。
