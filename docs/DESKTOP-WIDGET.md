# 0.2 桌面组件验证

环境：Windows 11 10.0.26200 x64，系统桌面由 Explorer 管理。日期：2026-09-29。

## 本次修改

- 默认 6 图标位，支持 4 图标位；固定尺寸，独立设置窗口。
- 默认位置锁；解锁后拖动顶栏，保存物理坐标。
- Windows 使用桌面宿主的子窗口，保持在普通应用窗口下方，并在显示桌面时可见。
- 使用屏幕坐标保存位置，再转换为桌面宿主坐标，兼顾主屏之外的位置。
- 保留独立小窗模式及其置顶开关。macOS 仅保留固定小窗结构，未验证。

## 自动检查

- `npm test`：30 项通过（27 项时间计算 + 3 项设置迁移/校验）。
- `npm run build`：TypeScript 类型检查和生产前端构建通过。
- `cargo check --release`：Windows Rust 编译检查通过。
- Playwright 浏览器脚本：独立设置、无效作息、保存/刷新、两档尺寸、午夜、休息、起床及舍入边界通过。

## 原生检查

Windows x64 最终发布版的 **10 组检查全部通过**，结果见 `output/playwright/windows-desktop-smoke.json`（`completed: true`）。脚本使用真实 Win+D 按键和真实鼠标拖动，检查 `WS_CHILD`、父窗口、系统命中测试和保存的物理位置；不会把“进程还在”当作“桌面上可见”。

1. 默认 6 图标位嵌入桌面、未置顶，当前 DPI/文字缩放下无溢出。
2. 普通设置窗口能遮住组件；打开设置不改变组件尺寸。
3. 真实 Win+D 后组件可见，并能被系统命中测试找到。
4. 锁定时拖动无效；解锁后真实鼠标拖动成功，物理坐标落盘。
5. 独立设置拒绝相同起睡时间，保存作息、4 图标位、主题及位置锁。
6. 两档布局在真实 WebView2 中均无内容溢出，截图已保存。
7. 系统关闭消息隐藏组件而不退出；再次启动显示原有桌面组件。
8. 将组件移到屏幕外后，自动回到可用屏幕。
9. 进程重启后恢复桌面嵌入、尺寸、作息、主题、位置锁与位置。
10. 桌面模式与普通小窗相互切换后保持可见，置顶开关正确生效。

`npm run desktop:build` 已成功生成 Windows x64 NSIS 安装包。上述检查运行的是实际发布版 exe；**安装器的安装/卸载流程未执行**。

检查中修正了原生 4 图标位布局的 1 像素溢出，以及通用窗口显示操作清除 `WS_CHILD` 导致脱离桌面层的问题。Windows 主组件统一用 Win32 管理显示、隐藏和置顶，设置窗口仍使用常规 Tauri 窗口。测试脚本也修正了松开鼠标后立即复位光标的竞态，并等待设置窗口的异步刷新。

## 验证边界

尚未验证：Explorer 进程重启、虚拟桌面切换、第三方动态壁纸软件、真实外接屏拔插、休眠唤醒、安装/卸载、托盘菜单实际点击。Windows 桌面宿主结构可能随系统版本变化；macOS 桌面层嵌入未实现，macOS 构建与运行未验证。
