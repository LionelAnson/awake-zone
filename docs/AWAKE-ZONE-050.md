# 0.5.0 醒时区名称与自定义作息

## 用户可见名称

应用窗口、设置窗口、托盘提示、安装包元数据和页面标题统一使用“醒时区 / Awake Zone”。内部 identifier、安装目录、可执行文件名、设置目录和 Windows 自启动项 `Personal Day` 保持不变，用于兼容已安装用户和已有设置。

## 自定义预期作息

设置页现在明确使用“预期起床时间”和“预期入睡时间”。保存后，清醒区间、醒时区时间、百分比和进度条都使用这两个时间重新计算。入睡时间早于起床时间按次日计算；相同时间仍提示无效。

设置页会实时预览当前作息和预计清醒时长。例如默认值显示为 `08:00 — 次日 00:00 · 预计清醒 16 小时 0 分钟`。

本轮保留北京时间 `Asia/Shanghai`、两位小数百分比、休息时段处理、桌面嵌入、Win + Alt + X、透明同心双环图标和已有本地设置。
