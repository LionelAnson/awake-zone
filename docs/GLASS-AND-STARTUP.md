# 0.3 磨砂、自启与右下角固定

日期：2026-09-29。环境：Windows 11 10.0.26200 x64，单屏 1920×1080，工作区 1920×1020。系统缩放与文字缩放沿用用户现有设置。

## 已完成的行为

- 隐藏清醒期倒计时及作息行；保留两个时钟标签、百分比与三个刻度。
- 休息期保留「上一清醒日已结束」和下次起床时间。
- 跟随系统颜色模式：亮玻璃黑字／暗玻璃白字，8px 圆角。
- 原生 Blur 在桌面子窗口上未生效，原生 Acrylic 接口返回失败。经用户确认，最终使用**壁纸取样磨砂**，保持桌面嵌入及 Win+D 可见。仅取样系统静态壁纸，不取样其他窗口或动态壁纸动画。
- 当前组件锁定在右下角，右边距 26 物理像素、距工作区底边 74 物理像素，与原位置边距相同。当前外框位置为 (1546, 760)，尺寸为 348×186 物理像素；其中包含系统非客户区，前端清醒期为 240×128 CSS 像素。
- 用户登录自启已开启，注册项指向已安装的 0.3.0 程序，命令为 `"E:\应用\Personal Day\personal-day.exe" --autostart`。

## 自动测试与原生检查

- `npm test`：**38 项通过**，包括原有 27 项时间计算、4 项设置迁移／校验、7 项壁纸坐标／布局换算。
- TypeScript 生产构建、Windows Rust 编译检查及 NSIS 打包通过。
- Playwright 浏览器检查通过：两档尺寸、删除两行、8px 圆角、半透明色值、深浅模式黑白文字、设置持久化、无效作息及时间边界。
- 真实发布版的 **13 组原生检查全部通过**，详见 `output/playwright/windows-desktop-smoke.json`：桌面嵌入、窗口遮挡、Win+D、锁定拖动、设置、自启注册／取消、尺寸切换时边距保持、关闭隐藏、再次启动、屏幕外位置恢复、重启恢复、浮窗切换。
- 用真实桌面合成截图检查壁纸取样磨砂，浅色／深色文字清晰，背景纹理经过模糊，布局无滚动条。截图：`glass-native-light.png`、`glass-native-dark.png`、`glass-native-background.png`。`glass-visual-probe.mjs` 用于复现；该脚本会切换桌面，需关闭正在运行的组件。

主题切换测试通过 WebView2 的系统颜色模式模拟完成；读取当前真实系统配置为浅色，实际运行也显示浅色。没有改动用户的 Windows 主题设置。
